    Every posting gets a score out of 100. JobDesk adds up points for each thing below that the posting matches, and takes points off for things you do not want.

        Where you can work

        A posting scores as local when its location contains your city or state. You can add suburbs and neighboring towns later in the Criteria tab, which is where local_terms lives.

        Money and hard nos

        On top of what JobDesk already screens out: unpaid, commission-only and multi-level marketing. Most postings list no salary, so the floor only counts against the ones that do.

        Companies worth watching

        Optional. JobDesk reads these employers' own job boards every morning, where postings show up days before the aggregators have them. It will tell you which command finds each board.

        Where finished work goes

        Optional. JobDesk copies each finished resume and packet to this folder too. Leave it blank to keep everything inside the project.

        Settings

        Changes save as you make them. They are kept on this computer, so a phone paired with JobDesk uses the same ones.

          Where your files go

          JobDesk builds everything in its own folder, and can copy each file to a folder you pick. Leave a box empty to skip the copy.

          Your profile

          Your details and work history live in a folder of plain text files. The Criteria tab edits the common parts. Open the folder for the rest.

          JobDesk on your phone

          Lets your phone open JobDesk. It writes a token to .env, listens on this machine's network address as well as loopback, and adds a task that starts it at logon. Scan the code once and the phone stays paired.

          Put JobDesk on the desktop

          Writes a shortcut that opens this window without a console behind it. Safe to click again after moving the project.
