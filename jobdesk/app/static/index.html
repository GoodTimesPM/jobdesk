What counts as a good job

This page is how JobDesk decides which postings to put at the top. Tell it what you want here, press Save, and every posting it already has is scored again straight away, so you can see what changed.

How a score works

Every posting gets a score out of 100. JobDesk adds up points for each thing below that the posting matches, and takes points off for things you do not want.

  • Title up to 35
  • Location up to 25
  • Skills up to 25
  • Experience up to 15
  • How new it is up to 10
  • Pay up to 11, when listed

The letter next to each score is a shorthand for it: A 75 and up is worth applying to today, B 60 to 74 is a good fit, C 45 to 59 is worth a look. Below 45 is hidden unless you ask for it.

Not sure why a job scored the way it did? Click it on the Jobs tab. The reasons are listed line by line, with the points each one was worth.

    Where you can work

    A posting scores as local when its location contains your city or state. You can add suburbs and neighbouring towns later in the Criteria tab, which is where local_terms lives.

    Money and hard nos

    Added to the list JobDesk already screens for: unpaid work, commission-only pay, and multi-level marketing. Most postings do not state a salary, so the floor only counts against the ones that do.

    Companies worth watching

    JobDesk checks these employers' own job boards every morning, where a posting shows up days before it reaches the aggregators. Optional: the general search runs regardless. Name them now and JobDesk will tell you which command finds each one's board.

    Where finished work goes

    Optional. Give a folder outside this project and JobDesk copies each finished resume and application packet there, so the files you work from are not buried in a code directory. Leave blank to keep everything inside the project.

    Settings

    Changes save as you make them. They are kept on this computer, so a phone paired with JobDesk uses the same ones.

    Appearance

    Where your files go

    JobDesk always builds resumes and application packets inside its own folder first. It can also copy each one to a folder of your choice, like the one where you keep the rest of your job search. Leave a box empty to skip the copy.

    Your profile

    Your details, work history and everything the Criteria tab edits live in a folder of plain text files. The Criteria tab covers what most people change. Open the folder to change anything else.

    JobDesk on your phone

    Turns this window into something your phone can open: a token is written to .env, JobDesk starts answering on this machine's network address as well as on loopback, and a task brings it back up at every logon — because the phone is the device you use when you are not at the desk. Scan the code once and the phone stays paired.

    Put JobDesk on the desktop

    Writes a shortcut that opens this window without a console behind it. Safe to click again after moving the project.
